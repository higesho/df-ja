Playable Races Revisioned（Steam ワークショップ ID 3665499038、作者 Vader）用の翻訳パックです。

dfint-ja が、この MOD で増える生き物・役職・作業・素材の名前を日本語で表示するために読み込みます。
MOD のフォルダには何も書き込みません。MOD を入れていない人には何の影響もありません。

訳を変えたいときは、この dictionary.csv の translation 列を書き換えてください。
ただし、このフォルダは dfint-ja を更新すると丸ごと入れ替わります。
変えた訳を残したい場合は、dfint-data/mods/ の下に別の名前のフォルダを作って
そちらに置いてください。名前が違うフォルダは更新で消えません。

訳の作り方（dfint-ja のフォルダで）:
  python tools/mod_template.py "<MOD のフォルダ>" "<出力先の dictionary.csv>"

くわしくは docs/mod-translation.md を見てください。
