# 文の部品の翻訳ルール（Dwarf Fortress 日本語化）

ゲームは英文を「書き出し（prefix）＋本体（core）＋後ろの句（suffix）」の部品をつなげて作ります。
例: `In {1}, ` ＋ `{1} struck down {2}` ＋ ` in {1}.` → "In 125, Urist struck down Bomrek in Lulartobul."

あなたはバッチ（JSON）の各部品を日本語にします。エンジンが日本語の部品を組み合わせて文にします。

## 出力の形式

1行に1部品、タブ区切りで4列。見出し行や説明は書かない。

```
group<TAB>kind<TAB>英語（バッチの text をそのまま）<TAB>日本語
```

- 英語の列は**一字一句そのまま**（空白も含めて）。変えると照合できなくなります。
- バッチのすべての部品を出力する。訳しようがないもの（意味の通らない断片）も、できる範囲で訳す。

## 差し込み {1} {2} …

- `{N}` は名前や物などが差し込まれる場所。日本語にも**同じ番号を全部**入れる（増やさない・減らさない）。語順は日本語に合わせて自由に動かしてよい。
- 各部品の番号はその部品の中だけのもの（prefix の {1} と core の {1} は別物）。
- バッチの `slots` に、各番号に入るものの種類が書いてある（人物名、場所名、年など）。助詞を選ぶ参考にする。

## 組み合わせ方（重要）

- 日本語の文 ＝ prefix の訳 ＋ core の訳（その中の `{REST}` の位置に suffix の訳が入る）＋ 句点。
- **core には `{REST}` を1つ入れる**。suffix（「〜で」「〜によって」など、述語の前に来る修飾）が入る場所。普通は述語（動詞）の直前。
  - 例: core `{1} struck down {2}` → `{1}は{REST}{2}を討ち取った`
  - suffix ` in {1}.` → `{1}で`
  - 組み上がり: 「125年、ウリストはルラトブルでボムレクを討ち取った。」
- suffix の訳は、述語の前に置ける形（「〜で」「〜によって」「〜と」）にする。文末の `.` は訳さない（エンジンが「。」を付ける）。suffix が `.` だけなら日本語は空にする。
- prefix の訳は文頭に付く形（「{1}年、」「{1}年、{2}は」など）。
- core の英語が `by` `with` `from` などで終わっていて後ろに名前が続く場合、その名前は suffix 側にある。`{REST}` を「〜によって」の前など自然な位置に置く（例: core `was shot and killed by ` → `{REST}によって射殺された`、suffix `{1}.` → `{1}`）。

## バッチの中身について

- 1つのバッチにはいろいろな関数の部品が混ざっている（歴史の出来事、詩や音楽の形式の説明、傷の描写、住民の思考、尋問の記録など）。group が同じものは同じ関数の部品。
- 部品は実行ファイルから機械的に取り出したもので、途中で切れた断片や、空白が2つ続くもの（間に何かが入る場所）もある。英語の列は変えずに、できる範囲で自然に訳す。
- 単語1つの見出し（建物名など）が混ざっていたら、普通に訳す。
- group が `txt_` で始まるもの（住民の発言・本の題名など）は、`{REST}` を入れなくてよい。本の題名は題名らしく（例: `A Treatise on {1}` → `{1}論`）。

## 訳し方

- 歴史・伝説の記述は常体（だ・である調、過去形「〜した」）。告知や説明は文脈に合わせる。
- 用語は `docs/glossary.md` と日本語Wiki（`translations/wiki-terms.tsv`）に合わせる。
- 簡潔に。画面の幅が限られる。
- `[C:7:0:0]` `[B]` などのトークンは原文どおり残す。
- 主語が prefix 側にあって core が動詞から始まる場合（例: prefix `In {1}, {2} `、core `died of old age`）は、prefix を「{1}年、{2}は」、core を「{REST}老衰で死んだ」のようにする。

## 例

```
b88530	prefix	In {1}, 	{1}年、
b88530	prefix	In {1}, {2} 	{1}年、{2}は
b88530	core	{1} shot and killed {2}	{1}は{REST}{2}を射殺した
b88530	core	{1} shot and killed {2} with {3}	{1}は{REST}{3}で{2}を射殺した
b88530	core	died of old age	{REST}老衰で死んだ
b88530	core	was shot and killed by 	{REST}によって射殺された
b88530	suffix	 in {1}	{1}で
b88530	suffix	{1}	{1}
b88530	suffix	{1} in {2}	{2}で{1}
```
