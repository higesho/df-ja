dfint-ja — Dwarf Fortress 日本語化MOD
======================================

Steam 版 Dwarf Fortress（Premium・Windows・バージョン 53.17）の画面表示を
日本語にします。


入れかた
--------

この zip の中身を、**Dwarf Fortress のフォルダにそのまま重ねてコピー**するだけです。

  （例）L:\SteamLibrary\steamapps\common\Dwarf Fortress\

コピーすると、次の3つが置かれます。

  dfhooks.dll           … 橋渡し役
  dfhooks_dfint_ja.dll  … 日本語化の本体
  dfint-data\           … 辞書・フォント・設定

ゲームのファイル（Dwarf Fortress.exe、data\ の中身）には一切手を加えません。

DFHack を使っている場合
  DFHack が先に入っていると `dfhooks.dll` がすでにあります。**そのまま上書きしない**で
  ください。残りの2つ（dfhooks_dfint_ja.dll と dfint-data\）だけコピーすれば動きます。
  あとから DFHack を入れた場合も、DFHack 側の dfhooks.dll に任せればそのまま動きます。


外しかた
--------

置いた3つを消すだけです。

  dfhooks.dll           （DFHack を使っている場合は消さないでください）
  dfhooks_dfint_ja.dll
  dfint-data\


使いかた
--------

- ゲーム中に **Ctrl+F2** で日本語化のオン／オフを切り替えられます。
- 文字が豆腐（□）になる場合は、dfint-data\fonts\ にフォントが入っているか確かめてください。


ほかのMODとの併用
----------------

生き物・品物・材質などを追加する MOD、タイルセット、グラフィック MOD とは
そのまま一緒に使えます。この日本語化はゲームのデータを読まず、画面に描かれる
文字だけを見ているためです。MOD を入れた世界に後から入れたり、外したりもできます。

- MOD が独自に足した名前は、辞書に無いので英語のまま表示されます。
  表示が崩れたり、半分だけ日本語になったりはしません。
- 名前がバニラの言葉を組み合わせた形（cave dragon など）の場合は、
  こちらが何もしなくても日本語になることがあります。
- MOD の名前も日本語にしたい場合は、下の「訳されていない文字を見つけたら」で
  ログを取り、GitHub の Issues で教えてください。自分で足す場合も、辞書
  （translations\）に書いて作り直すだけで、DLL には手を入れる必要はありません。

dfhooks.dll を使う MOD（DFHack のような DLL 形式のもの）だけは、同じファイルの
置き場所を取り合うため、そのままでは一緒に使えません。DFHack については
上の「入れかた」をご覧ください。


訳されていない文字を見つけたら
------------------------------

dfint-data\config.txt の

  [LOG_LEVEL:Warn]

を

  [LOG_LEVEL:Debug]

に変えてから遊ぶと、訳されていない文字列が dfint-data\dfint-log.log に残ります。
ログはゲームを起動するたびに書き直されるので、ゲームを終える前に取っておいてください。


できないこと・既知の制限
------------------------

- 人名・地名・世界で作られた名前（忘れられし獣の名前など）は英語のままです。
  ゲームが世界生成のときに作るもので、訳す対象がありません。
- 画面の幅はゲームが英語の文字数で決めているため、訳が長いと隣の表示と重なることが
  あります。目立つところ（交易の品物一覧など）は「…」で切るようにしてあります。
- DFHack を併用している場合、DFHack 自身の画面もほとんど日本語になりますが、
  タブの見出し（Automation など）とツール名は英語のままです。
- ゲームが更新されると、関数の位置が変わって動かなくなることがあります。
