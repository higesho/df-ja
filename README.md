# Dwarf Fortress — Japanese localization

*[日本語](README.ja.md)*

An unofficial, fan-made Japanese localization for Dwarf Fortress.
It targets the Steam release (Premium / Windows / **53.17**) and is not affiliated with the developer or publisher.

- Site: https://higesho.github.io/df-ja/ (Japanese)
- Download: [DwarfFortress_JP.zip](https://github.com/higesho/df-ja/releases/latest/download/DwarfFortress_JP.zip) ([all releases](https://github.com/higesho/df-ja/releases))
- Ultima series: https://higesho.github.io/ultima-ja/
- Might and Magic series: https://higesho.github.io/mm-ja/

**Nothing belonging to the game is modified.** `Dwarf Fortress.exe` and everything under `data\`
are left untouched — the mod only adds files. Delete them and you are back to English.

## What is translated

| Screen | State |
|---|---|
| Title, settings, world generation, arena | Done |
| Fortress mode (building, stocks, labor, nobles, trade, announcements, combat log) | Done |
| Adventure mode (character creation, conversation, combat) | Done |
| Legends mode (history, figures, artifacts) | Done |
| Names of creatures, items, materials and buildings | Done |
| Names generated at world creation (night creatures, demons, angels) | Done |
| DFHack's own interface (control panel, building planner, caravan trade) | Done |
| Personal names, place names, per-world generated names | Left in English — nothing to look up |

## Install

Download [DwarfFortress_JP.zip](https://github.com/higesho/df-ja/releases/latest/download/DwarfFortress_JP.zip)
and copy its contents into your Dwarf Fortress folder. Order does not matter.

```
Dwarf Fortress\
  dfhooks.dll           chainloader
  dfhooks_dfint_ja.dll  the translation engine
  dfint-data\           dictionaries, font, config
```

**If you use DFHack**, `dfhooks.dll` is already there. **Do not overwrite it** — copy the other two
items and it will work. Installing DFHack afterwards works too, with no changes.

To uninstall, delete those three (keep `dfhooks.dll` if you use DFHack).
Press **Ctrl+F2** in game to turn the translation on and off.

## Other mods

Raw mods (creatures, items, materials), tilesets and graphics mods work alongside this one.
Nothing in the game's data is read at run time — the engine only looks at the text being drawn —
so a modded world can have this added or removed freely.

- Names a mod adds are not in the dictionary, so they stay in English. Nothing is left
  half-translated: a name that cannot be looked up in full is drawn as it is.
- A name built out of vanilla words (`cave dragon`) may come out translated anyway, since names
  are composed from their parts.
- To get a mod's own names translated, log them (see below) and add them to `translations/`, then
  run `python tools/build.py`. The engine itself does not need touching.

The exception is a mod that ships its own `dfhooks.dll`. Only one such file can be in place, so it
cannot be used at the same time — DFHack is the case this mod handles specially (see [Install](#install)).


## Reporting problems

Please open an [issue](https://github.com/higesho/df-ja/issues) for mistranslations or text left in English.

Changing `[LOG_LEVEL:Warn]` to `[LOG_LEVEL:Debug]` in `dfint-data\config.txt` records untranslated
strings to `dfint-data\dfint-log.log`. Attaching that file helps a lot (it is rewritten on every
launch, so grab it before quitting).

## Translating it yourself

The dictionaries are tab-separated files under `translations/`. Write the English and the translation
side by side, run `python tools/build.py`, and that is it. **Swap the font and the dictionaries and
this works for languages other than Japanese** — only four places in the engine are language-specific.

See **[docs/translating.md](docs/translating.md)** (Japanese) for the full procedure, including how to
extract the source strings and how to check translations without starting the game.

## How it works

The engine hooks the functions the game uses to draw text, looks the English up in a dictionary and
draws the translation with its own font. See **[docs/architecture.md](docs/architecture.md)** (Japanese).

```
engine/        the translation engine (Rust) — builds to dfint_hook.dll
chainloader/   so that dfhooks.dll is not fought over with DFHack
translations/  translation sources (English<TAB>translation)
data/          what the engine reads (generated by tools/build.py)
tools/         extraction, build and checking scripts
docs/          how it works, how to translate, the site
```

### Building

Rust (rustup), the Visual Studio C++ build tools and Python 3.10+ are required.

```powershell
python -I -X utf8 tools/build.py                                      # translations/ -> data/
cd engine; cargo build --release; cd ..                               # the engine
cd chainloader; cargo build --release; cd ..                          # the chainloader
powershell -ExecutionPolicy Bypass -File .\install.ps1                # into the game folder
powershell -ExecutionPolicy Bypass -File .\tools\package.ps1 -Build   # the release zip
```
